# Mosca

Open-source end-to-end (E2E) test automation, inspired by Tricentis Tosca.

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Status: pre-alpha](https://img.shields.io/badge/status-pre--alpha-orange.svg)](#project-status)

## Overview

Mosca is an open-source test automation tool inspired by [Tricentis Tosca](https://www.tricentis.com/products/automate-continuous-testing-tosca). It provides a flexible and accessible alternative for creating, executing, and managing end-to-end (E2E) automated tests, helping software teams scale quality assurance effortlessly without proprietary costs.

## Project status

Mosca is in **pre-alpha**. Nothing is runnable yet: the repository currently contains documentation, contribution and security policies, and developer tooling configuration. Expect frequent breaking changes before 1.0.

## Features

**Available now:** none.

**Planned:**

- Create E2E automated tests.
- Execute E2E automated tests.
- Manage E2E automated tests.

Planned work follows the project goals: an open-source, flexible, and accessible alternative with no proprietary costs. Scope may change as the design evolves. [Open an issue](https://github.com/ram-ai-wq/mosca/issues) to suggest features.

## Getting started

Mosca has no release yet, so there is nothing to install or run. To follow progress, watch the repository on GitHub.
